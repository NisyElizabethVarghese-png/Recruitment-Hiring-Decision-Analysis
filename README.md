# Recruitment & Hiring Decision Analysis Using Python

## Project Overview

This project analyzes recruitment and hiring data using Python to explore candidate profiles, assessment scores, and hiring outcomes. Data cleaning, preprocessing, exploratory data analysis (EDA), and data visualization are used to identify recruitment patterns and examine the factors associated with candidate selection.

## Project Aim

To analyze recruitment and hiring data using Python to identify hiring patterns, evaluate candidate assessment scores, examine the relationship between candidate characteristics and selection outcomes, and generate data-driven insights that can support informed, fair, and effective recruitment decisions.

## Project Objectives

- Understand the structure and characteristics of the recruitment dataset.
- Clean and preprocess the data to improve its quality and consistency.
- Perform exploratory data analysis to identify patterns and trends.
- Examine candidate assessment scores and hiring outcomes.
- Visualize relationships between candidate characteristics and hiring decisions.
- Summarize key findings and identify potential areas for further investigation.

## Dataset Description

The project uses an AI Fair Recruitment Dataset containing candidate information, assessment scores, and hiring decisions.

**Dataset source:** [Kaggle — AI Fair Recruitment Dataset](https://www.kaggle.com/datasets/roiiith/ai-fair-recrutment-dataset)

The dataset includes variables such as gender, age, education level, experience, skill score, aptitude test score, technical test score, communication score, interview score, job role applied for, expected salary, and hiring decision.

## Tools and Technologies

- **Python** — Data analysis and processing
- **Pandas** — Data manipulation and cleaning
- **NumPy** — Numerical operations
- **Matplotlib** — Data visualization
- **Seaborn** — Statistical visualizations
- **Jupyter Notebook** — Analysis and documentation

## Project Workflow

1. **Data Loading and Initial Overview** — Load the dataset and examine its structure, dimensions, data types, and summary statistics.
2. **Data Cleaning and Preprocessing** — Identify missing values, handle duplicate records, standardize inconsistent values, and prepare variables for analysis.
3. **Exploratory Data Analysis (EDA)** — Analyze candidate characteristics, assessment scores, and hiring outcomes.
4. **Data Visualization** — Use appropriate charts to explore distributions, comparisons, and relationships.
5. **Insights and Conclusions** — Summarize the patterns observed and discuss their implications for recruitment analysis.

## Key Areas of Analysis

- Candidate demographic and educational profiles
- Distribution of applicants across job roles and locations
- Candidate assessment score distributions
- Comparison of assessment scores by hiring outcome
- Hiring patterns across education and experience categories
- Relationships between assessment scores
- Potential recruitment fairness considerations

## Key Findings

The main findings are documented in the Jupyter Notebook. They focus on candidate assessment scores, hiring outcomes, and patterns observed across the dataset.

## Limitations

The findings describe patterns in the available dataset and do not establish that any factor caused a hiring decision. Conclusions about fairness depend on data quality, variable definitions, and the limitations of the dataset.

## Project Files

- `Recruitment_Hiring_Decision_Analysis.ipynb` — Jupyter Notebook containing the analysis, visualizations, and explanations.

## Conclusion

This project demonstrates the use of Python for data cleaning, exploratory data analysis, and visualization in a recruitment context. It provides an opportunity to examine hiring patterns and generate evidence-based observations that may support further investigation into recruitment practices.
